KI-Titel-/Regisseurprüfung einrichten

Diese Version läuft komplett lokal, ohne Claude-Cloud. Für die automatische Titel- und Regisseur-Prüfung braucht sie einen eigenen Anthropic-API-Key (separat von deinem Claude.ai-Konto, eigene Abrechnung nach Nutzung – für diesen Zweck typischerweise Cent-Beträge). Ohne Key funktioniert die App genauso, nur ohne die automatische Prüfung.

→ API-Key bei console.anthropic.com erstellen

Der Key wird ausschließlich lokal in deinem Browser gespeichert (localStorage) und nur direkt an Anthropics API gesendet – niemals an einen anderen Server.

Sicherung

Deine Daten liegen nur in diesem Browser. Mit einer Sicherung kannst du sie auf ein anderes Gerät mitnehmen oder wiederherstellen.

Punkt/Chip anklicken: Status wechseln (gefüllt = besitze ich) · ✎ bearbeiten · „⇅ Anordnen“ oder ⠿ ziehen: Kategorien umsortieren oder in andere Ordner legen · ↶ macht die letzte Änderung rückgängig. Alles wird automatisch gespeichert.
